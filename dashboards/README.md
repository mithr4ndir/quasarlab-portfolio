# Dashboards

Curated Grafana dashboards and static screenshots for the portfolio.

## What is here

- Sanitised JSON exports of representative dashboards. TODO.
- PNG snapshots sourced from the live showcase instance, for the static
  Tier 1 showcase (see `docs/security/public-showcase.md`).

## Conventions

- Dashboards are authored and versioned in `observability-quasarlab`.
  What lands here is either an export (JSON) or a static capture (PNG).
- No real hostnames, IPs, or alert content in any dashboard committed
  here. Use scrubbed recording rules.
